# Visual Form Builder

Complete planning documents for Niral's public MERN project, using Next.js for
the React frontend and a separate Express API. This folder contains documentation,
not runnable application code.

## Repository

Public repository: [Niralempiric/visual-form-builder](https://github.com/Niralempiric/visual-form-builder).

The local implementation folder is `/home/empiric-60/Public/project/ghfind-score/visual-form-builder`.
The `main` branch tracks `origin/main`. The planning documents are already in
`docs/`; use this repository for subsequent implementation tasks. Preserve the
progress history and verify the current code before selecting a task.

The plan contains **40 day groups, 120 tasks and 24 modules**. Each task has a
prerequisite and an individual completion check. Estimate 5 to 6 focused hours
per day group, around 200 to 240 hours total. One invocation completes one task;
three invocations generally finish a day group. Once per calendar day means up
to 120 days for 120 tasks, not a guaranteed forty-day finish.

D01.1 is a short product contract. Application setup begins in D01.2, with a
running Next.js page and Express liveness route planned for D01.3. Later
milestones add immutable publishing, responses, safe CSV, conditional and
multi-step forms, roles, templates, retention and release checks.

All planned work remains unchecked until verified in the implementation repository.
